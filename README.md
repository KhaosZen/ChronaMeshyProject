# ROOTED（工作名）— Meshy × Chrona 3D 世界创作赛参赛作品

一栋被树占据的楼，玩家在里面循环。每次循环楼有细微变化，树又长了一点，碎片散落各处，永远拼不出完整答案。爬到树顶，循环停止。

- **截止**：2026-10-09 07:59（北京时间）
- **平台**：[Chrona.world](https://chrona.world)，上传单个 HTML 文件
- **参考**：P.T.（碎片、压迫感、不解释）＋ 8号出口（重复中的异常）＋ 长进楼里的树
- **风格**：Low poly，哑光，muted colors，无高细节贴图
- **技术**：Three.js（CDN）＋ 外链 GLB（Meshy 导出）＋ 单 HTML

## 运行

```bash
python3 -m http.server 8000   # GLB 外链需要 http 访问，不能直接双击打开
# 浏览器打开 http://localhost:8000/        正常模式
#            http://localhost:8000/?debug  调试：显示坐标，数字键 1-5 跳循环
```

## 结构

```
index.html            全部逻辑（按编号分节：配置 / 平台适配层 / 占位几何体 / 资产加载 / 物理 / 关卡 / 循环 / 控制 / 拾取）
assets/               Meshy 导出的 GLB，文件名见 docs/assets.md
docs/assets.md        资产清单、尺寸、朝向约定
docs/chrona-checklist.md  Chrona 平台待确认项与对应代码位置
```

资产替换：把 GLB 放进 `assets/`，在 `index.html` 的 `ASSETS` 里填 `file`，其余不用改。没有 GLB 或载入失败时自动使用程序化占位体。

## 循环系统

| 循环 | 变化 | 实现 |
|---|---|---|
| 1 | 灯亮，路线畅通，道具散落 | ✅ |
| 2 | 一盏灯灭，一扇门被根堵住，字迹第 1 行 | ✅ |
| 3 | 窗外光傍晚→正午，捡过的道具原位长出新根，字迹第 2 行 | ✅ |
| 4 | 布局微变，灯全灭只剩窗外光，字迹第 3 行 | ✅ 占位（门变墙、椅子移到走廊中央） |
| 5 | 树冠穿透，爬主干到树顶，循环停止；捡过特定道具则树顶细节不同 | ⬜ 占位（到平台直接结束） |

每轮根和主干都会长大一点。当前循环触发点：走到楼梯顶平台 → 黑场 → 回到走廊起点。
