# ROOT（工作名）— Meshy × Chrona 3D 世界创作赛参赛作品

一个离家多年的孩子，被困在关于老家的记忆里。大海中央一栋被树占据的废弃楼，每层解开谜题才能上楼，否则永远留在同一层。从压抑、无色走到明亮、有色，最后在天台走进传送门——回家。

- **截止**：2026-10-09 07:59（北京时间）
- **平台**：[Chrona.world](https://chrona.world)，上传 ZIP（index.html + assets）≤ 200 MiB，发布即公开
- **设计文档**：Claude Docs「ROOT 设计文档」（玩法、叙事、谜题池、资产清单、概念图提示词）
- **技术**：Three.js + 外链 GLB（Meshy API 生成）

## 运行

```bash
python3 -m http.server 8000
# http://localhost:8000/?debug   调试：显示楼层/谜题/钥匙；1–5 跳楼层，K 拿齐本层钥匙
```

## 打包上传 Chrona

```bash
npm install
npm run pack        # → dist/root.zip（index.html + assets + 本地化的 three，不依赖 CDN）
```

## 灰盒现状

每层同一布局：直角走廊 → 过渡房间 → 楼梯。

- **找「钥匙」**：每层有若干把，每把随机抽一个谜题模板和 8 个摆放点之一。
- **过渡房间**：进门后身后的门关上，按结果播内心独白。
  - 拿齐了：剧情台词。
  - 没拿齐：抽一句提示台词。
  - 交互错过：迷茫台词。
- **楼梯**：房间尽头的门打开，走上楼梯，中途黑一下，无缝接到下一层或本层起点。
- **外观**：从一楼到四楼，色板由灰到彩，光由暗到亮，植物逐层增多。
- **天台**：天井里长出巨树，四周是海，远处的歪楼上也长着树。走进传送门后白场，显示用时和体验过的谜题数。
